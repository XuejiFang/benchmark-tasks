# Third-party assets

The files under `assets/vendor/simready_usd` include the monitor geometry and textures from the [LG Electronics SimReady assets dataset at revision 96684f4c9c6205aef8f53abc9a09ce0f49234507](https://huggingface.co/datasets/LGElectronics/simready-assets/tree/96684f4c9c6205aef8f53abc9a09ce0f49234507/monitor_27gx790a), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The copied USD and textures are unmodified. The separate `assets/stand.usda` composes the source monitor and adds and overrides simulation properties as described in the task README.
